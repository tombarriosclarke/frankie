# Assets to drop in here

The site works without these (it falls back to labelled placeholders), but it comes alive when you add them:

| file | used for | notes |
|---|---|---|
| `frankie-cutout.png` | spinning loader | full-body or head-and-shoulders cutout, **transparent background**, ~800px tall |
| `frankie-face.png` | Start button, start menu, Spirit Guide | just the face, transparent background, square-ish, ~400px |
| `book-cover.jpg` | 3D book | front cover of The Toxic Travel Guide, 2:3 ratio |

Everything else is hotlinked from Frankie's public YouTube thumbnails.
